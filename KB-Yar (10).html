🔁 مرور حافظه‌سپاری

☁️ همگام‌سازی با GitHub

بک‌آپ کامل (کارت‌ها، عکس‌ها، فایل‌ها) به‌صورت چند تکه‌ی ZIP (به‌همراه یک فایل فهرست) در یک ریپوی خصوصی GitHub ذخیره می‌شود.
۱) در GitHub یک ریپوی خصوصی بساز (با README).
۲) Settings ← Developer settings ← Fine-grained tokens: توکنی فقط برای همان ریپو با دسترسی Contents: Read and write بساز.
بک‌آپ به چند فایل مستقل تقسیم و یکی‌یکی ارسال می‌شود؛ هر تکه در صورت خطا خودکار دوباره امتحان می‌شود.
اگر بگذاری، فایل روی GitHub رمزگذاری AES-256 می‌شود. رمز را فراموش نکن؛ بدون آن بازیابی ممکن نیست.
توکن فقط در حافظه‌ی همین مرورگر (localStorage) ذخیره می‌شود و فقط به api.github.com ارسال می‌شود. «ارسال» و «دریافت» فقط تغییرات را جابه‌جا می‌کنند (تکه‌های بدون تغییر دوباره منتقل نمی‌شوند). بک‌آپ‌های قدیمی هم هنوز قابل دریافت‌اند؛ بعد از اولین «ارسال» جدید، همگام‌سازی تدریجی فعال می‌شود. حجم کل محدودیتی ندارد؛ فقط یک کارت (با عکس و فایل‌هایش) نباید از ۹۰ مگابایت بیشتر باشد.
